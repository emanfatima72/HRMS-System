===================================== 
HRMS System - Installation Guide 
===================================== 
 
Requirements: 
1. PostgreSQL 14+ installed 
2. Python 3.10+ (for zip version) 
 
Installation Steps: 
1. Install PostgreSQL 
2. Create database: hrms_db 
3. Configure .env file 
4. Run HRMS_System.exe 
 
Default Login: 
HR: hr / hr@portal1166 
Admin: admin / admin@portal1166
